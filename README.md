# Cybersecurity Threat Intelligence, Analysis, Risk Scoring and Monitoring Platform

A cybersecurity platform for collecting, analyzing, scoring and monitoring threat indicators.

## Technology Stack

- React
- Python
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions
- Kubernetes
- Prometheus
- Grafana

## Main Flow

Threat Ingestion
→ Threat Analysis
→ Risk Scoring
→ Database
→ Alerts
→ Dashboard
